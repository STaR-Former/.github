# ⭐️ STaRFormer

📘 Organization Overview

Welcome to the official GitHub organization for the [STaRFormer](https://neurips.cc/virtual/2025/poster/116860) project. This space hosts the project page and implementation, datasets, and experimentations of [NeurIPS-2025] [STaRFormer: Semi-Supervised Task-Informed Representation Learning via Dynamic Attention-Based Regional Masking for Sequential DataSequential Data](https://neurips.cc/virtual/2025/poster/116860)..

Our goal is to provide a clear, reproducible, and extensible framework for researchers and practitioners interested in exploring or building upon STaRFormer.

Whether you're here to reproduce our results, examine the model internals, contribute improvements, or integrate STaRFormer into your own work, we’re excited to have you involved.
